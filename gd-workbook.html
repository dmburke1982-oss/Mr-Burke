Testing Modes

🟢 Training Mode

  • • No time limit
  • • Use the lightbulb for step-by-step help
  • • Questions can be retried
  • • Best for learning and targeted review

🔴 Testing Mode

  • • Timed to match exam conditions
  • • No help text available
  • • No question retries
  • • Best for baseline and exam practice

Daily Practice Workflow

1.Open GMetrix SMS v6 → Sign in
2.New Test → Adobe → Photoshop → Select Training or Testing Mode
3.Save before the period ends (maximum 15 saves per test)
4.Use Resume Test to continue saved work next class
5.Use Completed Tests to view scores and review missed questions
